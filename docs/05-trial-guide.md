# 社内試用ガイド（v0.1.0）

> 対象: 試用に協力してくれる新人・研修担当・社内開発者
> フィードバックは GitHub の Issue「試用フィードバック」テンプレートで送ってください（チャットで伝えてもらっても構いません）。

## 1. インストール

1. [Releases](https://github.com/ASIL-E-Hatake/vscode-games/releases) から最新の `hatake-gottani-x.y.z.vsix` をダウンロードする
2. 次のどちらかでインストールする
   - ターミナルで実行:
     ```bash
     code --install-extension hatake-gottani-0.1.0.vsix
     ```
   - VS Code の拡張機能ビュー（`Ctrl+Shift+X`）右上の「…」→「VSIX からのインストール…」でファイルを選ぶ
3. 左端のアクティビティバーに鍋のアイコンが出れば完了。クリックするとメニューが開く

- 対応: VS Code 1.120 以上（Windows / Mac / Linux）
- 新しい版が出たら、同じ手順で上書きインストールする（記録や個人リンクは消えない）
- アンインストール: 拡張機能ビューで「Hatake ごった煮ツールボックス」→「アンインストール」

## 2. 試してほしいこと

全部でなくて構いません。気になったところだけでも教えてください。

| 機能 | 試してほしいこと |
|---|---|
| ホーム | 今日のひとこと・最近使った機能・自己ベストが役に立つか |
| はじめての VS Code | 画面の名前・ショートカット・困ったときは が新人に分かりやすいか、足りない項目はないか |
| Linux コマンド辞書 | 引きたいコマンド・レシピが見つかるか（検索の当たり方）、説明の分かりやすさ |
| 言語別チートシート | 研修で使う書き方が載っているか、言語の比較表示が役に立つか |
| リンク集 | 個人リンクの追加、エクスポートしたファイルを別の人がインポートできるか、共有ファイルの設定 |
| コードタイピング | 1 分の長さ・お題の難しさ、日本語入力がオンのときの警告 |
| 反射神経テスト | 遊びやすさ |
| スライドパズル | 4×4 の難しさ、タイルの見やすさ |
| 全体 | 自分のテーマ（ライト / ダーク / ハイコントラスト）で見づらいところ、キーボードだけで操作できるか |

## 3. 知っておいてほしいこと（既知の制限）

- **外部への通信は一切しません。** 記録や個人リンクは自分の PC（VS Code の保存領域）にだけ保存されます。
  - 個人リンクは VS Code の Settings Sync をオンにしていれば、ほかの PC にも同期されます
- 社内リンクは同梱していません。チームで共有する方法は [README の「リンクをチームで共有する」](../README.md#リンクをチームで共有する) を参照
- 効果音は既定でオフです（設定 `hatake-gottani.sound.enabled`）
- ゲームを表示したくない場合は、設定 `hatake-gottani.games.enabled` をオフにするとメニューから消えます
- アイコンは仮のデザインです
- ショートカットの表記は Windows が基準です（はじめての VS Code の画面では Mac 表記に切り替えられます）

## 4. フィードバックの書き方

Issue テンプレート「試用フィードバック」に次を書いてもらえると助かります。

- どの機能で、何をしようとして、どうなったか（不具合ならできれば手順とスクリーンショット）
- 使っている OS・VS Code のバージョン（「ヘルプ」→「バージョン情報」）・テーマ
- 「こんな機能・コンテンツがほしい」も歓迎します（[機能バックログ](02-feature-backlog.md) に反映します）

## 5. 研修担当の方へ

- 研修用のリンク集は、ファイル（YAML / JSON）を作って共有フォルダに置き、各自の設定 `hatake-gottani.links.sharedFiles` にパスを指定してもらうと、ファイルの更新が全員に反映されます
- 研修用のリポジトリに `.vscode/hatake-gottani.links.yaml` を置けば、そのフォルダを開いた人全員にリンクが表示されます（フォルダを「信頼済み」にしている場合）
- 辞書・チートシートは「調べ方・書き方」を示すもので、研修課題の解答は載せていません
